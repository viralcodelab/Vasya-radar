# 🤖 Лид-Радар Telegram Bot

Автоматический мониторинг Telegram-каналов для поиска заказов на веб-дизайн, верстку и разработку сайтов.

## Возможности

- Мониторинг каналов через Telethon и предварительный фильтр по ключевым словам.
- Обязательная AI-проверка каждого кандидата перед отправкой.
- Карточка лида с кнопкой генерации отклика и ссылкой на исходное сообщение.
- Для AI нужны переменные `AI_API_KEY`, `AI_BASE_URL` и `AI_MODEL` в `.env`.

## 🚀 Быстрый старт

**Читайте файл: START_HERE.md**

Там пошаговая инструкция по запуску на бесплатном хостинге за 10 минут!

### Краткая версия:
1. Загрузите код на GitHub
2. Подключите к Render.com
3. Авторизуйтесь (введите код из SMS)
4. Готово! Бот работает 24/7

## Каналы

Список источников находится в `config/channels.json`; его также можно менять командами `/add_channel` и `/remove_channel`.

## 🛠 Команды бота:
- `/start` - Запуск и приветствие
- `/help` - Справка
- `/channels` - Показать список каналов
- `/add_channel @channel` - Добавить канал
- `/remove_channel @channel` - Удалить канал
