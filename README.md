# Лид-Радар Telegram Bot 🎯

Telegram-бот для автоматического мониторинга каналов и поиска заказов на веб-дизайн, верстку и разработку сайтов.

## 🚀 Возможности

- ✅ Автоматический мониторинг Telegram-каналов
- ✅ Фильтрация сообщений по ключевым словам
- ✅ Классификация лидов по категориям (Веб-дизайн, Верстка/Frontend, Разработка)
- ✅ Исключение спама через минус-слова
- ✅ Форматированные уведомления со ссылками на сообщения и авторов
- ✅ Управление списком каналов через команды бота
- ✅ Логирование работы и ошибок

## 📋 Требования

- Python 3.8+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- Telegram API credentials (получить на [my.telegram.org](https://my.telegram.org))

## 🛠 Установка

1. **Клонируйте проект или скопируйте файлы**

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте конфигурацию:**

Скопируйте `.env.example` в `.env` и заполните данные:
```bash
cp .env.example .env
```

Отредактируйте `.env`:
```env
# Токен бота от @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# API credentials с my.telegram.org
API_ID=12345678
API_HASH=0123456789abcdef0123456789abcdef

# Ваш номер телефона для userbot
PHONE_NUMBER=+1234567890

# Ваш Telegram User ID (узнать можно у @userinfobot)
ADMIN_ID=123456789
```

4. **Настройте список каналов (опционально):**

Отредактируйте `config/channels.json` для добавления/удаления каналов:
```json
[
  "designer_ru",
  "designhunters",
  "zakaz_design"
]
```

## 🎮 Запуск

```bash
python main.py
```

При первом запуске вам потребуется:
1. Ввести код подтверждения, отправленный на ваш номер телефона
2. Возможно, ввести пароль 2FA, если он включен

## 📱 Команды бота

После запуска напишите боту в Telegram:

- `/start` - Запуск бота и приветствие
- `/help` - Справка по командам
- `/channels` - Показать список отслеживаемых каналов
- `/add_channel @username` - Добавить канал в мониторинг
- `/remove_channel @username` - Удалить канал из мониторинга

## ⚠️ Важные замечания

1. **FloodWait**: Telegram может ограничивать частоту запросов. Бот обрабатывает это автоматически с задержками.

2. **Приватность**: Userbot использует ваш личный аккаунт. Используйте ответственно.

3. **API Limits**: Telegram API имеет лимиты. Не добавляйте слишком много каналов одновременно.

4. **Безопасность**: Никогда не публикуйте файл `.env` с вашими токенами!

## 🐛 Устранение неполадок

### Бот не запускается
- Проверьте правильность токенов в `.env`
- Убедитесь, что установлены все зависимости
- Проверьте логи в `logs/bot.log`

### Не приходят уведомления
- Проверьте, что каналы добавлены командой `/channels`
- Убедитесь, что userbot авторизован (введен код из SMS)
- Проверьте логи на наличие ошибок

### Ошибка FloodWait
- Бот автоматически обрабатывает эти ограничения
- Подождите указанное время и повторите попытку

## 📝 Логи

Все логи сохраняются в `logs/bot.log` и выводятся в консоль.
